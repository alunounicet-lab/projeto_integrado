# Como usar este pacote no VS Code + Codex

1. Faça uma cópia de segurança ou branch de trabalho no repositório do grupo; preserve alterações locais dos colegas.
2. Extraia o ZIP e **copie o conteúdo da pasta `eventsync_codex/` para a raiz do repositório** aberta no VS Code, lado a lado com `index.html`, `styles.css`, `app.js` e `README.md`. Não substitua os arquivos existentes com código.
3. Abra o Codex apontando para o workspace do projeto (não para a pasta do ZIP).
4. Copie e cole o conteúdo de `prompts/01_INICIAR_NO_CODEX.md` no chat do Codex.
5. Revise a versão criada no navegador e peça correções específicas antes de avançar.
6. Cole `prompts/02_REFINAR_E_REQUISITOS.md` para implementar os padrões tecnológicos depois que as telas estiverem boas.

Os SVGs em `references/` são mockups **esquemáticos originais** criados para comunicar medidas, cores e hierarquia visual. Não são arquivos do sistema nem imagens idênticas às prévias do ChatGPT. Você pode também salvar capturas das prévias da conversa na mesma pasta e informar ao Codex que elas têm prioridade visual.

Os arquivos do GitHub foram examinados em 28/10/2026 na branch `main`. A cópia local pode conter mudanças mais recentes.
