# EventSync — Plataforma de Divulgação e Participação em Eventos

## 1. Sobre o Projeto
## Título e descrição do problema de negócio atendido.
O **EventSync** é uma aplicação web desenvolvida para divulgar eventos públicos e privados, permitindo que os usuários encontrem eventos de seu interesse e confirmem sua participação. A plataforma também oferecerá notificações sobre novos eventos e atualizações relacionadas aos eventos nos quais o usuário estiver inscrito.

## 3. Requisitos Tecnológicos

O desenvolvimento do EventSync contemplará os seguintes eixos tecnológicos:

- **Acessibilidade e UX Inclusiva:** criação de uma interface acessível, intuitiva e adequada a diferentes usuários.
- **Tempo Real e Reatividade:** atualização de informações e notificações utilizando tecnologias adequadas, como WebSockets, SSE ou Broadcast Channel.
- **Edge Computing, Performance e Sustentabilidade Digital:** adoção de estratégias como Edge Functions, cache, Green Web e formatos de imagem AVIF/WebP.
- **Tendências Emergentes e Novos Padrões da Web:** utilização de recursos como Web Components, Web Workers e Notifications API, conforme as necessidades da aplicação.
